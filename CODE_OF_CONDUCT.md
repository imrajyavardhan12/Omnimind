# Code of Conduct

OmniMind follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
Be excellent to each other.

## Our standards

- **Be direct and kind.** Critique the code and the architecture, never the person.
- **Assume competence.** Ask what constraint drove a decision before rewriting it.
- **Keep it small.** Reviewable PRs, honest handoffs, docs with every contract change.
- **No surprises.** Security issues stay private until fixed; breaking changes get
  an ADR and a migration path.

## Unacceptable behavior

Harassment, discrimination, sexualized language, trolling, doxxing, or any
conduct that makes contributors feel unsafe or unwelcome — in issues, PRs,
discussions, or any project space.

## Enforcement

Violations can be reported privately to the maintainer (see GitHub profile).
All reports are confidential. The maintainer may warn, temporarily ban, or
permanently remove contributors who violate this code, with reasons communicated
to the involved parties.

## Scope

This applies everywhere the project lives (repo, issues, PRs, discussions) and
when representing OmniMind publicly.
